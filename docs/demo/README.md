# README demos

These 10-second looping GIFs are excerpts from actual Claude Code walkthroughs recorded on 2026-10-12 with DataFog MCP 1.0.0 and Core 0.4.4. All customer records are synthetic. `scan.gif` comes from flow 3; `transform.gif` comes from flow 5.

The clips retain the flow title, prompt, tool progress, and result. Cropping removes the Claude startup banner and unused terminal space; no tool output is reconstructed or altered. They use 8 frames per second and a 96-color palette at 1,000 pixels wide.

The transform example explicitly selects EMAIL, SSN, CREDIT_CARD, PHONE, DATE, and ZIP_CODE. Both names stay in every copy. Counts of zero on a later scan would mean no selected matches, not anonymity.

The sample CSV and text files match the original inputs shown in the clips. Save them inside your allowed roots to repeat the walkthrough.
