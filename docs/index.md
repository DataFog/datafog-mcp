# datafog-mcp

`datafog-mcp` is an MCP server and proxy for PII-aware tool output handling in AI agent systems.

## Key goals

- Provide MCP tools for scanning and redacting sensitive content.
- Offer a transparent proxy mode that applies redaction automatically.
- Keep everything local and ergonomic for developer workflows.
